BACKEND API TESTING - CURL COMMANDS
====================================

Base URL:
http://localhost:5000


B1 - GET /
--------------------

Request:

curl.exe http://localhost:5000/

Expected Response:

{
  "status": "ok"
}

Expected Status:
200 OK


B2 - GET /api/projects
--------------------

Request:

curl.exe http://localhost:5000/api/projects

Expected Status:
200 OK

Expected Result:
Returns an array containing all projects.


B3 - GET /api/projects/:id
--------------------

Valid Request:

curl.exe http://localhost:5000/api/projects/personal-portfolio

Expected Status:
200 OK

Expected Result:
Returns the project with ID "personal-portfolio".


B3 - Failure Case: Invalid Project ID
--------------------------------------

Request:

curl.exe http://localhost:5000/api/projects/invalid-id

Expected Status:
404 Not Found

Expected Response:

{
  "error": "Project not found"
}


B4 - POST /api/contact
--------------------

Valid Request:

curl.exe -X POST http://localhost:5000/api/contact -H "Content-Type: application/json" -d "{\"name\":\"Ravi\",\"email\":\"ravi@gmail.com\",\"message\":\"Hello from API testing\"}"

Expected Status:
201 Created

Expected Result:
Contact submission is successfully stored.


B4 - Failure Case: Invalid Email
--------------------------------

Request:

curl.exe -X POST http://localhost:5000/api/contact -H "Content-Type: application/json" -d "{\"name\":\"Ravi\",\"email\":\"invalid-email\",\"message\":\"Testing invalid email\"}"

Expected Status:
400 Bad Request

Expected Response:

{
  "error": "Invalid email format"
}


B4 - Failure Case: Missing Name
-------------------------------

Request:

curl.exe -X POST http://localhost:5000/api/contact -H "Content-Type: application/json" -d "{\"email\":\"ravi@gmail.com\",\"message\":\"Testing missing name\"}"

Expected Status:
400 Bad Request

Expected Response:

{
  "error": "Name is required"
}


B5 - GET /api/contact
--------------------

Request:

curl.exe http://localhost:5000/api/contact

Expected Status:
200 OK

Expected Result:
Returns an array containing all stored contact submissions.

Note:
This endpoint is intentionally open and does not require authentication.


B6 - Invalid Route / 404
------------------------

Request:

curl.exe http://localhost:5000/invalid-route

Expected Status:
404 Not Found

Expected Response:

{
  "error": "Route not found"
}


B7 - CORS and Environment Configuration
----------------------------------------

Environment configuration:

PORT=5000
DATA_FILE_PATH=data/projects.json
ALLOWED_ORIGIN=http://localhost:5173

The backend uses dotenv to load environment variables and CORS to allow requests from the configured frontend origin.

The .env file is not committed to GitHub.
The .env.example file is included in the repository.


B7 - CORS Test
--------------

Request from the frontend origin:

curl.exe -i -H "Origin: http://localhost:5173" http://localhost:5000/api/projects

Expected Result:
The response should contain an Access-Control-Allow-Origin header
corresponding to the configured frontend origin.
